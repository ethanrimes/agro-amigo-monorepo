# Imágenes de AgroAmigo

[fetch_images.py](fetch_images.py) descarga imágenes de familias faltantes y conserva las selecciones existentes. El manifiesto de [atribución](../../apps/web/src/lib/image-library.json) registra archivo, título, autor, licencia, URL de origen y SHA-256. La aplicación sirve los archivos locales y expone los créditos en `/credits`.

Las imágenes son referencias visuales. Una foto de familia no confirma la variedad, el empaque comercial ni la identidad exacta del producto. Las ilustraciones y las imágenes genéricas se identifican como tales. Las categorías de servicios y equipos usan una representación apropiada en lugar de asumir que todos los insumos son fertilizantes.

La selección de una imagen necesita revisión visual y de licencia antes de publicarse. El descargador no convierte una coincidencia de búsqueda en una identificación verificada.
